About

  • Each site is a single page that works in any browser, on a phone too, with search built in. No sign-up, no ads, no tracking.
  • The lists are read from the Steam copy of the game and rebuilt after game updates; each card shows the game version it was built from.
  • These are unofficial pages, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media.
  • Found a mistake or have an idea? Open an issue on GitHub for that site: Console Commands, Item IDs, Locations, Game Settings, Record Types, Tracking on Nexus Mods. A free GitHub account is needed.
